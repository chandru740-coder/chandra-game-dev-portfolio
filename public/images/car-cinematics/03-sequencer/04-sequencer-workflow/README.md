# Sequencer workflow

Add screenshots of the Unreal Engine Level Sequencer. Prefer screenshots
showing Camera Cuts, multiple CineCameraActor tracks, and the timeline.

Suggested filenames:

- `sequencer-camera-cuts.png`
- `sequencer-multiple-cameras.png`

JPG is also acceptable; keep the base filenames consistent and change only
the extensions, for example `sequencer-camera-cuts.jpg`.
