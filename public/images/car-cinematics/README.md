# Car Cinematics screenshots

Organize the automotive project screenshots in the numbered folders below.
Use JPG or PNG, and keep filenames consistent so the page can reference them
reliably. Add only screenshots and rendered frames from the actual project.

- `01-environment/01-garage-overview/`: widest view of the premium garage and red sports car; suggested filename: `garage-overview.png`.
- `01-environment/02-garage-details/`: garage architecture, glass, reflective platform, or lighting; suggested filename: `garage-details.png`.
- `02-camera-setup/03-camera-angles/`: CineCameraActor placement and composition around the vehicle; suggested filename: `camera-setup.png`.
- `03-sequencer/04-sequencer-workflow/`: Level Sequencer Camera Cuts, multiple CineCameraActor tracks, and timeline; suggested filenames: `sequencer-camera-cuts.png` and `sequencer-multiple-cameras.png`.
- `04-final-frames/05-cinematic-stills/`: selected final rendered frames only; suggested filename: `cinematic-still-01.png`.

The suggested names use PNG; JPG is also fine. If choosing JPG, keep the same
base names and use the `.jpg` extension consistently.
